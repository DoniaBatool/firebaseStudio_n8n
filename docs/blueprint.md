# **App Name**: Excuse Generator 2025

## Core Features:

- Input Text Box: A text input field where the user enters the basic premise or context for the excuse they need.
- Generate Excuse: Generative AI creates a tailored excuse using the provided text context, which acts as a tool the AI leverages.
- Copy Excuse: A 'Copy to Clipboard' button allowing users to quickly copy the generated excuse.
- POST Request Integration: Upon generating an excuse, the app makes a POST request to `http://localhost:5678/webhook-test/a63df51a-7c0f-4221-bae9-1365f4693862` with the user-provided text, which is the core behavior described in the request.

## Style Guidelines:

- Primary color: A vibrant purple (#A052DE) evoking creativity.
- Background color: A very light purple (#F5EEF8), a pastel version of the primary, which serves as a calming neutral background to accentuate content.
- Accent color: A warm pink (#E91E63) to highlight key actions and interactive elements.
- Body and headline font: 'Inter' (sans-serif) to maintain a modern, readable, and neutral presentation, focusing on readability above all else.
- Code font: 'Source Code Pro' for displaying code snippets.
- Use simple, outline-style icons for clarity and a modern aesthetic.
- Emphasize clear hierarchy and readability, ensuring ease of use. This includes using whitespace and logical content grouping.
